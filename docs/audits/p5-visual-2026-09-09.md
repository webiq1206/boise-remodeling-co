## Reproduce the slider state regression

The P5 parent repository includes `scripts/qa/p5-slider-regression.cjs`. Check out the four service repositories beside the parent repository and install the parent's dependencies. In a temporary test-runtime folder with a `package.json`, install `react@18.3.1` and `react-test-renderer@18.3.1`. Run the script with `P5_AUDIT_ROOT` set to the folder containing the four repositories and `P5_TEST_RUNTIME` set to the temporary runtime folder. No production dependency changes are required.
